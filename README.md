# Arendur Atlas

An interactive atlas of the **Arendur Rising** campaign, as the Shadow Company knows it: Ursia, East Blackwood and the town of Delios.

Site: https://bahnegork.github.io/Arendur-Atlas/

**This repo is generated.** It holds only the players' edition of the atlas. The workflow "Publish players' edition" builds it every hour from the GM repo (`Arendur-Atlas-GM`), which writes only what the players may see. Don't edit files here; changes are overwritten by the next build.

Pins moved on the site with **Gem for alle** are saved in the GM repo.

Built with Leaflet 1.9.4 (BSD-2-Clause) and marked 12.0.2 (MIT).
